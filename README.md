# To-Do List App

A small browser-based to-do list app using `localStorage` so tasks remain saved after refreshing the page.

## Files
- `index.html`
- `styles.css`
- `app.js`

## Run locally
Open `index.html` in a browser.

## Features
- Add tasks
- Mark tasks complete/incomplete
- Edit tasks
- Delete tasks
- Filter: All / Active / Completed
- Clear completed tasks
- Persist tasks with browser `localStorage`
